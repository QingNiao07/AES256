AES-256 加密工具箱 v1.3
========================
本地离线加密 · 单一总密钥 · 多算法叠加 · 桌面/移动双端
作者：青鸟（Qingniao）  <qingniao2007@126.com>

本软件是一款通用数据加密工具，完全本地离线运行。
使用前请先阅读并接受《法律声明与免责协议》（docs/LEGAL.md）。
⚠ 只有本人勾选"我接受"后，才能完成安装或首次使用。


============================================================
一、安装（必须先接受声明）
============================================================
方式 A · 图形安装向导（推荐）
    python install.py
    → 第 1 步阅读《法律声明与免责协议》 → 勾选"我接受" → 完成安装

方式 B · 命令行安装（需输入"我接受"确认）
    python install.py --cli

方式 C · 无界面安装（自动化；必须显式 --accept 表示本人已接受）
    python install.py --quiet --accept --who 你的名字

仅检查环境（不安装）
    python install.py --check

说明：安装会初始化配置、创建日志目录 aes_log/，并记录法务接受信息
（写入 config.json 的 legal 段 + 审计日志，可追溯）。
未勾选"我接受"时安装会被终止，且不会写入任何接受记录。


============================================================
二、启动
============================================================
· 图形版（PySide6，推荐）：python aes256_qt.py
· 图形版（Tkinter，轻量）：python aes256_tool.py
· 命令行：python cli.py --help
· 打包后：双击 AES256Tool.exe（首次启动 5-15 秒属正常）

首次启动会弹出同一份《法律声明与免责协议》，勾选"我接受"后才能进入。


============================================================
三、三步开始使用
============================================================
1. 输入密码 → 点"缓存密码"
2. 把文件拖进窗口 → 自动加密（生成 .aes256）
3. 把 .aes256 文件拖进窗口 → 自动解密

【两条铁律】
· 永远不要删除密钥文件
· 首次使用不要勾选"删除原文件"（确认流程无误后再启用）

【立即做】
点【导出密钥文件】保存到 U 盘，并抄写一份恢复码（抗介质损坏）


============================================================
四、多加密方式与叠加加密（v1.1+）
============================================================
· 菜单【文件 → 选择加密方式…】，或命令行 `python cli.py list-ciphers`
· 可单选一种算法，也可勾选多种"叠加"（自上而下依次加密）
· 无论叠加几种算法，始终只使用一个总密钥（密码只派生一次，
  各层子密钥由 HKDF 域分离得到）
· 支持：AES-256-GCM / AES-256-OCB3 / ChaCha20-Poly1305 /
        AES-256-CBC+HMAC / Camellia-256+HMAC / CAST5 / Blowfish / 3DES
· 命令行示例：
    python cli.py enc 文件 --chain aes-256-gcm
    python cli.py enc 文件 --chain aes-256-gcm,chacha20-poly1305
    python cli.py dec 文件.aes256        # 解密自动识别算法链
· 详见 docs/MULTI_CIPHER.md

============================================================
八、移动版（手机 / 平板）
============================================================
本工具箱提供两种移动端形态，均支持与桌面端 v4 容器互通：

1) 移动网页版（PWA，推荐 · 只需浏览器 · 完全离线）
   启动本地服务：python mobile/serve.py
     · 本机试用：浏览器打开 http://127.0.0.1:8765/
     · 手机访问：python mobile/serve.py --host 0.0.0.0
       电脑与手机连同一 Wi-Fi，手机浏览器打开 http://<电脑IP>:8765/
   · 可"添加到主屏幕"，像 App 一样打开；首次加载后离线可用
   · 浏览器限制：仅支持【AES-256-GCM】单层 + 【PBKDF2】派生

2) Kivy 原生移动版（Android / iOS，支持全部 8 种算法与叠加）
   运行：pip install kivy  →  python mobile/kivy_app.py
   打包 Android：cp mobile/buildozer.spec buildozer.spec; buildozer -v android debug

【桌面 ⇄ 移动 互通】
   · 桌面端生成（供手机解密）：
       python cli.py enc 文件 --kdf pbkdf2
       （可选 --kdf-iters 600000，两端需一致）
   · 手机端生成的 .aes256 拷回电脑：python cli.py dec 文件.aes256
   · 说明：桌面端默认 Argon2id 容器仍可用桌面端解密；
     跨端请统一使用 --kdf pbkdf2。
   · 无论叠加几层算法，始终只使用一个总密钥。

   详见 docs/MOBILE.md
