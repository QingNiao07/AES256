# 威胁模型（THREAT MODEL）

## 保护目标

1. 静态文件机密性：磁盘上的 `.aes256` 在无密码时不可读。
2. 完整性：任何对密文/头部的篡改、重排、截断都可检出。
3. 密钥材料：密码与主密钥不泄露到日志或网络。

## 信任边界

- **可信**：用户本机、用户输入的密码、保险库文件 `vault.json`。
- **不可信**：网络、云盘、共享目录、AI 服务端。
- **默认离线**：AI 功能需显式开启，且出网前脱敏。

## 防御矩阵

| 威胁 | 防御 |
|------|------|
| 暴力破解 | Argon2id 内存硬化 + 可配置强度 + 尝试次数上限 |
| 字典攻击 | 随机 per-vault 盐 + 强度可调 |
| nonce 重用 | nonce = 前缀(4) ‖ 块序号(8)，序号进 nonce 与 AAD |
| 密文篡改 | 每块 GCM tag + AAD 绑定头部 |
| 密文重排/删除块 | 块序号绑定 AAD 与 nonce |
| 文件截断 | 尾部 HMAC-SHA256 覆盖全部块 |
| 头部篡改 | 头部进入 AAD 与 HMAC |
| 内存残留 | securemem 擦除 |
| 审计日志篡改 | 哈希链 + `audit_verify.py` 定位断点 |

## 不防御（超出范围）

- 已攻陷的操作系统 / 键盘记录器 / 内存取证（解锁态）。
- 弱密码（策略仅警告，不强制拒绝）。
- 用户主动泄露密码或恢复码。
- 冷启动攻击、物理拆解。

## 密钥丢失

密码丢失**无法恢复**。缓解手段：密钥文件 + 恢复码（11 组 × 5 字符）离线备份。

## 依赖风险

- `cryptography` 提供 AES-GCM；`argon2-cffi` 提供 Argon2id。
- 二者缺失时分别回退到下层的软件实现 / PBKDF2，安全性相应下降，`doctor.py` 会提示。
